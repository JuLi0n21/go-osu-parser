# OsuParser [![Pipeline](https://github.com/JuLi0n21/go-osu-parser/actions/workflows/pipeline.yml/badge.svg)](https://github.com/JuLi0n21/go-osu-parser/actions/workflows/pipeline.yml)

Small go based Library to Read osu! dbs and .osu files

```go
import "github.com/juli0n21/go-osu-parser/parser"
```

```bash
get github.com/juli0n21/go-osu-parser@latest
```

[Examples](./pkg/example.go)

Currently Supported files:
-   osu!.db
- scores.db
- collection.db

- .osu files
